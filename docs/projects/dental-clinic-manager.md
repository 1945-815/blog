# 牙管家

## 项目背景

面向口腔诊所日常运营管理，包括患者预约、诊疗订单、项目管理和审批。

## 系统功能

- 患者预约和诊疗项目管理。
- 诊疗订单处理与重复订单校验。
- JWT 身份认证与权限校验。
- Activiti 7 审批流程部署、任务处理及记录查询。
- Vue 前端与后端接口联调。

## 技术栈

Spring Boot、MyBatis、MySQL、Redis、JWT、Activiti 7、Vue。

## 概念性技术流向

> 以下为便于说明职责边界的概念示意，不表示实际生产环境的部署或服务拓扑。

```text
Vue 页面 → Spring Boot REST API → MyBatis / MySQL
                  ├─ JWT 认证与权限校验
                  ├─ 事务与重复订单校验
                  └─ Activiti 7 审批任务与记录查询
```

## 本人职责

- 参与患者预约和诊疗项目管理。
- 参与 Spring 事务和重复订单校验。
- 参与 Activiti 7 审批流程部署、任务处理及记录查询。
- 参与 JWT 认证、权限校验、项目上下架及前后端联调。
