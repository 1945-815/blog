## 三、核心代码实现

## 延伸：面试问答

### 你具体负责什么？

按简历可以说明在团队指导下负责文档管理检索和审批相关模块，并列出本人实际完成的接口或功能；更细粒度只讲自己能举例验证的部分。

### 为什么同时用 MySQL 和 Elasticsearch？

MySQL 保存业务数据，Elasticsearch 侧重全文检索；同步延迟和重建方案需要按项目实际情况说明。

### 如何证明 RAG 不是简单调用模型？

说明文档处理、检索结果、上下文构造和来源返回；没有亲自验证的细节不声称为个人实现。
