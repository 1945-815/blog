## 20 篇重点文章提纲

### 1. Java 集合的选择：List、Set、Map 分别解决什么问题

- **背景与问题：**不同查询、顺序和去重需求如何选择结构。
- **方案与实现：**对比 `ArrayList`、`HashSet`、`HashMap` 的典型用法，配上可运行小例子。
- **踩坑与优化：**说明空值、可变对象作为键、迭代修改等容易误用的情形。
- **总结：**用“访问方式和数据约束”总结选择依据。

### 2. Stream API 的常见用法与容易忽略的副作用

- **背景与问题：**集合转换、筛选和聚合为什么容易写成难读的链式调用。
- **方案与实现：**用 `filter`、`map`、`collect` 展示清晰的数据流。
- **踩坑与优化：**讨论副作用、状态共享、过长链路；必要时改为普通循环。
- **总结：**按可读性和调试难度选择写法。

### 3. Spring Boot 接口中的参数校验与统一错误响应

- **背景与问题：**多接口如何保持输入校验和错误格式一致。
- **方案与实现：**DTO 校验、业务异常和全局异常映射。
- **踩坑与优化：**区分参数错误、权限错误和业务规则错误，避免返回内部异常细节。
- **总结：**列出接口层职责及可复用的错误结构。

### 4. 用 MyBatis-Plus 实现条件筛选和分页查询

- **背景与问题：**列表接口要支持多个可选过滤条件。
- **方案与实现：**查询 DTO、条件构造、分页对象和返回 DTO。
- **踩坑与优化：**校验页码、排序字段白名单及空条件，避免把实体直接暴露为响应。
- **总结：**展示一条从请求到 SQL 结果的链路。

### 5. 数据库事务、索引与重复提交问题

- **背景与问题：**预约或订单重复写入，以及事务边界如何划分。
- **方案与实现：**事务、唯一约束、状态校验的职责对比，提供核心 SQL 和伪代码。
- **踩坑与优化：**解释事务不能单独解决并发重复请求，结合唯一约束做最终防线。
- **总结：**用并发时序图说明处理顺序。

### 6. Redis TTL 在验证码和临时状态管理中的应用

- **背景与问题：**临时数据需要自动失效，避免永久残留。
- **方案与实现：**键命名、写入、读取、过期时间和刷新流程。
- **踩坑与优化：**处理过期、重复发送和日志泄露风险；说明 TTL 是存储策略的一部分。
- **总结：**给出本地可运行的最小示例。

### 7. Spring Security 与 JWT 的认证授权流程
